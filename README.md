# Life OS

这是从现有线上 **Life OS Weekly Planner v1** 恢复出的工程化基线。

## 恢复原则

- 不重新设计产品；
- 先恢复 Weekly Planner 的结构、文案和主要交互；
- 浏览器本地持久化继续使用 `localStorage`；
- 基线稳定后，再开发 `Build = 内容 + 日期 + 时间`；
- Build 后续增加日 / 周 / 月 / 年统计。

## 当前已恢复

- Weekly Overview
- 本周完成度
- Health / Wealth / Experience / Career / Inner 五个模块
- 09.07–09.13 基线周的 16 条任务
- 任务完成 / 取消完成
- 新增任务
- 编辑 / 删除任务
- 上一周 / 本周 / 下一周
- 浏览器本地持久化
- 移动端响应式布局

## Build v1

Build 已加入主工程，但保留 Weekly Planner 作为独立视图。

当前能力：
- 快速记录内容
- 日期 + 时间
- 浏览器本地持久化
- 日 / 周 / 月 / 年筛选统计
- 记录数 / 活跃天数 / 全部累计
- 删除记录

数据仍保存在当前浏览器的 `localStorage`，下一阶段可迁移到云端存储。

记录时可以填写投入时长（分钟）；Build 页面按日、周、月、年展示累计时长柱状图。升级前已有的记录继续保留，但因为没有时长字段，会显示“未记录时长”。
每条记录可选择五个 Life OS 模块之一。统计区可以切换“全部 OS”或单个模块，记录列表与时长图表会同步筛选；旧记录可通过“编辑”补上模块和时长。

Weekly Planner 打开时默认显示设备本地日期所在的周（周一至周日），旧任务和勾选状态保留。2026-09-21 至 09-27 周补充了旅行记录、身体照顾与周复盘任务；这些任务只会加入一次，后续每周可自行添加计划。
2026 年 9 月剩余日期及整个 10 月的计划放在 `src/sep-oct-plan.json`：旅行、离职交接、简历与 AI 数据学习、求职、财务核对和生活复盘按天安排。升级时只追加一次，用户后续的勾选、编辑和删除不会被覆盖。
