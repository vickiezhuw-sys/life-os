# V0.9 Today 验收记录

## 实际功能

- Project 35 显示当天 Build 记录累计时长、300 分钟目标、达成率和差额，不自动生成记录。
- Top 3 可选/取消，过滤已删除或移走的任务引用；不同设备种子 UUID 去重后仍关联到正确任务。
- Top 3、随手记按日期保存并带修改时间；较新的清空操作不会被旧设备覆盖。旧版没有修改时间的数据保留兼容策略。
- 随手记即时写入本地，避免切换页面时丢失防抖队列中的文字。
- 日终复盘保存用户填写的推进情况和明日下一步，展示实时任务完成数及真实投入。
- 过期未完成任务可逐项安排到今天，保留原任务与来源，不自动完成，不生成 Build，重复点击不重复创建。
- 修正任务行四个元素的网格布局，增加窄屏换行和长文本处理。
- 新字段随现有 JSON 快照备份、导入和云同步。

## 自动验证

39 项 Node 测试通过，覆盖 V0.8 安全补丁、重点限制/取消、UUID 引用迁移、同日新旧快照、空值操作、备份往返、复盘保存、结转幂等和 Build 不变。
锁文件对应 Vite 7.3.7 生产构建通过；Windows 沙箱使用 --configLoader runner。

## 人工验收

1. 新增四个今日任务，依次设重点；第四个被阻止，取消一个后可重新选择。重载检查。
2. 输入随手记后立刻切换 Weekly，再回 Today，确认内容保留。
3. 保存日终复盘，导出 JSON，再导入，核对复盘、重点、Build 和任务。
4. 将一个未完成的旧任务安排到今天，确认原任务仍存在、今日任务带来源、Build 分钟不变。
5. 两台运行新版的设备测试同一天重点取消、笔记清空、复盘修改，以及不同时期的日期记录共存。
6. 在 375/390/768px 和桌面宽度检查按钮、长标题、键盘输入、复盘与结转操作；检查所有导航。
